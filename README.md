# APP RRHH · Vacaciones

App para que cada empleado pida sus vacaciones, avise de citas y vea los días que le quedan, y para que el administrador apruebe solicitudes y registre ausencias y bajas.

- La app (esta página) se instala en el móvil desde el navegador.
- Los datos se guardan en la hoja de Google Sheets "APP RRHH - Vacaciones" del administrador, a través del código de `servidor/Codigo.gs` (Apps Script). En este repositorio no hay datos de empleados.
